API活用フロー

はじめての方向け。選定から本番実装までの5ステップです。

STEP 1 APIを選ぶ

「API台帳」で用途・カテゴリから候補を探し、信頼度ランク・接続優先度・事業適合度で比較して選定します。

STEP 2 利用条件を確認

APIキーの要否・認証方式・ライセンス・商用利用可否・最終確認日をチェック。商用は license_note を必読。

STEP 3 接続方式を理解

データ形式ごとに呼び出し方が異なります。下の「データ形式別 接続早見表」で方法を確認します。

STEP 4 試し接続で検証

サンプルエンドポイントで疎通確認。台帳の検証結果（成功 / 応答時間 / 取得サイズ）も参照できます。

STEP 5 アプリに実装

endpoint_template を組み込み、属性表記・利用規約を遵守して本番運用へ。成果物エクスポートも活用できます。

データ形式別 接続早見表

形式に応じた典型的な使い方と、該当する代表的なAPIです。

データ形式 典型的な使い方 代表的なAPI
XYZ タイル (PNG/JPG) Leaflet / MapLibre にタイルURL {z}/{x}/{y} を登録して地図表示 地理院 地図・標高・ハザードタイル
ベクトルタイル (PBF) MapLibre / Mapbox GL でスタイル定義して参照 地理院 ベクトルタイル
GeoJSON / JSON fetch() で取得し属性解析・地図描画 気象庁 予報・警報, USGS 地震
3D Tiles / CityGML CesiumJS など対応ビューア・SDK で読み込み PLATEAU 3D都市モデル
Shapefile / GML QGIS / GDAL で変換し GIS で利用 国土数値情報 (KSJ)
CSV / 観測JSON ETL・時系列解析で取り込み AMeDAS, USGS 水文, OpenAQ
最小実装例（XYZタイルを地図に表示）
// Leaflet
const map = L.map('map').setView([35.68, 139.76], 12);
L.tileLayer(
  'https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png',
  { attribution: '地理院タイル' }
).addTo(map);

スコア算定基準

各スコアは台帳の項目から算定式で自動計算した評価値です（実測値ではありません）。個別の内訳は「API台帳」の各行詳細で確認できます。

事業適合度 0–100

  • 提供元種別：公的/国際/公式 +30・財団 +22・企業 +12
  • 商用利用：可 +25・条件付 +12・不明 +8
  • 更新頻度：高頻度 +15・その他 +10
  • 対象案件：1件あたり +7（最大 +20）
  • 接続状態：本格利用候補 +10 … 調査中 +2

連携実装性 0–100

  • APIキー：不要 +30・不明 +12・必要 +8
  • 認証方式：なし +15・APIキー +8
  • データ形式：扱いやすい(JSON/タイル) +20・要変換 +10
  • エンドポイント：具体的 +15・雛形 +8
  • ドキュメント +10 / 実接続検証 成功 +10

信頼度ランク A–E

  • 公的/国際/公式/財団 +30
  • 公式ドキュメント +20 / ライセンス明記 +20
  • 更新頻度 +10 / データ形式 +10 / 検証成功 +10
  • 合計 90↑=A・70↑=B・50↑=C・30↑=D

接続優先度 1–5

  • 信頼度 × 0.30
  • 事業適合度 × 0.35
  • 連携実装性 × 0.20
  • 対象案件規模 × 0.15
  • 合計 85↑=5・70↑=4・55↑=3・40↑=2
