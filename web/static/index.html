API活用フロー

はじめての方向け。選定から本番実装までの5ステップです。

STEP 1 APIを選ぶ

「API台帳」で用途・カテゴリから候補を探し、信頼度ランク・接続優先度・事業適合度で比較して選定します。

STEP 2 利用条件を確認

APIキーの要否・認証方式・ライセンス・商用利用可否・最終確認日をチェック。商用は license_note を必読。

STEP 3 接続方式を理解

データ形式ごとに呼び出し方が異なります。下の「データ形式別 接続早見表」で方法を確認します。

STEP 4 試し接続で検証

サンプルエンドポイントで疎通確認。台帳の検証結果（成功 / 応答時間 / 取得サイズ）も参照できます。

STEP 5 アプリに実装

endpoint_template を組み込み、属性表記・利用規約を遵守して本番運用へ。成果物エクスポートも活用できます。

データ形式別 接続早見表

形式に応じた典型的な使い方と、該当する代表的なAPIです。

データ形式典型的な使い方代表的なAPI
XYZ タイル (PNG/JPG)Leaflet / MapLibre にタイルURL {z}/{x}/{y} を登録して地図表示地理院 地図・標高・ハザードタイル
ベクトルタイル (PBF)MapLibre / Mapbox GL でスタイル定義して参照地理院 ベクトルタイル
GeoJSON / JSONfetch() で取得し属性解析・地図描画気象庁 予報・警報, USGS 地震
3D Tiles / CityGMLCesiumJS など対応ビューア・SDK で読み込みPLATEAU 3D都市モデル
Shapefile / GMLQGIS / GDAL で変換し GIS で利用国土数値情報 (KSJ)
CSV / 観測JSONETL・時系列解析で取り込みAMeDAS, USGS 水文, OpenAQ
最小実装例（XYZタイルを地図に表示）
// Leaflet
const map = L.map('map').setView([35.68, 139.76], 12);
L.tileLayer(
  'https://cyberjapandata.gsi.go.jp/xyz/std/{z}/{x}/{y}.png',
  { attribution: '地理院タイル' }
).addTo(map);
