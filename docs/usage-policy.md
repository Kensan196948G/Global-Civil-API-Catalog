# 利用方針

## データ登録

台帳へ登録するデータソースは、公式提供元、準公式団体、国際機関、広く利用されるOSSコミュニティを優先します。スクレイピングを前提にしたデータ取得や、利用条件が不明なデータの本格利用は禁止します。

## 必須項目

各APIには、公式URL、利用条件、APIキー要否、データ形式、更新頻度、信頼度、最終確認日を記録します。未確認の項目は推測せず `unknown` または `調査中` として扱います。

## 秘密情報

APIキー、トークン、Cookie、個人情報、社内機密、本番データは保存しません。認証が必要なAPIの検証は、環境変数またはシークレット管理を使う実行環境でのみ行います。

## 後続プロジェクト連携

後続プロジェクトで採用するAPIは、`connection_status` を `本格利用候補` に設定し、`adoption_reason` と `target_projects` を必ず記録します。
